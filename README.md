# Диктофон Pro для Android 🎙️

Современное мобильное приложение-диктофон для Android смартфонов с аппаратным захватом звука, визуализацией волновой формы, кодированием в **MP3 128 кбит/с (по умолчанию)**, библиотекой записей, недеструктивным аудио-редактором и корзиной с 30-дневным хранилищем.

---

## 📱 Основные возможности

### 1. Запись аудио (FR-1 — FR-9)
- **Старт/стоп в одно касание:** Крупная сенсорная кнопка записи (≥96dp) со световой индикацией статуса.
- **Двухканальный VU-метр (L/R):** Точное отображение уровней громкости от -24dB до 0dB.
- **Индикатор клиппинга (CLIP):** Мгновенный сигнал при превышении входного уровня и перегрузе.
- **Живой осциллограф:** Плавная анимация спектра и волны речи в реальном времени.
- **Пауза и возобновление:** Запись можно приостановить и продолжить в тот же аудиофайл.
- **Фоновая служба (Foreground Service):** Эмуляция шторки Android с таймером и кнопками «Пауза» / «Стоп».
- **Защита от сбоев (.part журнал):** Автоматическое обнаружение незавершённой сессии при старте с предложением восстановить запись.

### 2. Качество и форматы (FR-10, FR-37)
- **Формат по умолчанию:** **MP3, 128 кбит/с (CBR), 44.1 кГц, `.mp3`** (на базе `@breezystack/lamejs`).
- **Дополнительные профили:**
  - **Высокое (FLAC):** Lossless, 48 кГц (для музыки и студийных интервью).
  - **Стандарт (AAC):** 128 кбит/с, 44.1 кГц (компактный размер).
  - **Экономный (Opus):** 32 кбит/с, 48 кГц (для голосовых заметок).
  - **Совместимый (WAV):** PCM 16-bit, 44.1 кГц (чистый звук без сжатия).
- **Стерео / Моно переключатель.**
- **Предусилитель (Gain):** 0.5× – 3.0× с аппаратным лимитером и VAD-обрезкой тишины.

### 3. Диалог сохранения и валидация имён (FR-4)
- Автоматически открывается сразу после нажатия кнопки «Стоп».
- Подставляет автоимя по шаблону `Запись YYYY-MM-DD HH-mm-ss`.
- **Проверка уникальности (`E_NAME_EXISTS`):** Автоматически предлагает свободный вариант (`Запись … (2)`, `… (3)`).
- **Валидация (`E_NAME_INVALID`):** Ограничение 1–100 символов, проверка на запрещённые знаки (`/ \ : * ? " < > |`) и пробелы.
- Опция «Сохранить под автоименем» гарантирует нулевую потерю аудиоданных.

### 4. Библиотека записей (FR-13 — FR-18)
- Группировка по дням («Сегодня», «Вчера», даты).
- Поиск по названиям, заметкам и тегам.
- Фильтрация по избранному и тегам (`#Работа`, `#Идеи`, `#Интервью`).
- Сортировка: новые/старые, по названию (А-Я), по длительности.
- Контекстное меню: редактирование, переименование, отправка (`Web Share`), экспорт файла, перемещение в корзину.

### 5. Плеер и мини-плеер (FR-19 — FR-23)
- Интерактивная волна (Waveform) с перемещаемым ползунком прокрутки.
- Перемотка на -10 сек / +10 сек.
- Регулировка скорости воспроизведения (0.5×, 0.75×, 1.0×, 1.25×, 1.5×, 2.0×).
- Интеграция с системной панелью Android (`navigator.mediaSession`).
- Заметки к записи и управление тегами.
- Плавающий мини-плеер при переходе между вкладками.

### 6. Редактор аудио (FR-24 — FR-26)
- Недеструктивная обрезка краёв (**Trim**).
- Вырезание фрагмента из середины (**Cut**).
- Разделение файла на две части (**Split**).
- Мгновенный предпросмотр результата и сохранение новой копии в MP3.

### 7. Безопасность и хранилище (FR-31 — FR-36)
- **Корзина:** Удалённые файлы хранятся 30 дней с обратным отсчётом дней до удаления и восстановлением в 1 клик.
- **PIN-код:** 4-значный код безопасности на вход в приложение.
- **Резервная копия:** Экспорт и импорт базы данных в JSON.
- **Статистика:** Число записей, суммарная длительность, занятое и свободное место.
- **Локализация:** Русский (по умолчанию) и English.

## 🛠️ Стек технологий

- **Фреймворк UI:** React 19, TypeScript
- **Стилизация:** Tailwind CSS v4, Lucide Icons, Motion
- **Аудио-ядро:** Web Audio API (`AudioContext`, `AnalyserNode`, `ScriptProcessorNode`)
- **Кодирование:** `@breezystack/lamejs` (MPEG-1 Layer 3 CBR), PCM WAV
- **Локальное хранилище:** IndexedDB (для аудио-блобов и волн) + LocalStorage
- **Сборщик:** Vite 8, `vite-plugin-pwa`
- **Тестирование:** `node:test` + `node:assert/strict` (13 юнит-тестов)

## 🚀 Установка и запуск

### Быстрый старт локально

```bash
# 1. Клонирование репозитория
git clone https://github.com/ea1982m/dictophone-android.git
cd dictophone-android

# 2. Установка зависимостей
npm install

# 3. Запуск сервера разработки
npm run dev
```

Приложение откроется по адресу `http://localhost:3000`.

### Запуск юнит-тестов

```bash
npm test
# или
npx tsx --test src/utils/recorder-logic.test.ts
```

### Сборка продакшен-версии

```bash
npm run build
```

## 📦 Получение APK-файла для Android

### Способ 1. Мгновенная установка WebAPK (без сторонних инструментов)
1. Откройте приложение в браузере **Google Chrome** на смартфоне.
2. Нажмите кнопку **APK** в шапке приложения или выберите в меню Chrome: **«Установить приложение»** / **«Добавить на главный экран»**.
3. Android автоматически создаст полноценный нативный пакет (WebAPK) с отдельной иконкой, офлайн-работой и доступом к микрофону.

### Способ 2. Сборка APK через PWABuilder (в 1 клик)
1. Откройте сервис [PWABuilder](https://www.pwabuilder.com).
2. Вставьте URL развернутого приложения.
3. Нажмите **«Package for Android»** ➔ скачайте готовый подписанный `.apk` для установки или `.aab` для Google Play.

### Способ 3. GitHub Actions CI/CD
Репозиторий включает готовый workflow `.github/workflows/android.yml` для автоматической сборки APK с помощью Tauri 2 / Gradle при каждом коммите в ветку `main`.
